Source Map Importer

Map

Browse for a map, or drop one anywhere on this window. A compiled .bsp, or a workshop .gma with a map inside, gives the best result. A .vmf works too, but has no embedded content and no 3D-skybox detection. Keep its custom content in a folder with the same name next to it.

Anything here overrides the base games and files packed in the map. A folder can hold loose content or a pile of .vpk files.

Base games

Where stock textures and models come from. The map's own game is mounted automatically when the map is inside a game's maps folder.

Options

Build

Turns the reviewed map into small geometry files and separate textures. Nothing leaves this PC at this step.

    Upload to Roblox

    Uploads every kept texture and geometry file to this account with Open Cloud. Only assets that passed review are in the build. Re-running resumes: anything already uploaded is skipped.

    Then, in Roblox Studio

    Open the Source Map Importer plugin and press Build in Workspace. Keep this app running: the plugin reads the build from it.
